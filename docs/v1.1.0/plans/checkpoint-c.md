## Decisions to confirm (none needs a new ADR unless you disagree)
1. **`eligible_users` view** is dropped and recreated unchanged inside migration 16 (the TRD's rebuild recipe does not mention it, and the rename would fail without it). Not a TRD conflict, but worth knowing.
2. **`PUT /themis/goals/:id/subjects` "needs Melete":** a user without Melete gets 404 from the route, like other gated routes.
3. **Floor of 1 second** for a measured session when `melete_final_card_seconds` is 0, so the `seconds > 0` CHECK can't fail an answer.
4. **Goal time by week** (12 weeks) is the shape of `GET /themis/goals/:id`; the TRD says "time by week" without a length.
