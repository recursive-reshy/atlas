# Plan — Checkpoint C: Web restructure (v1.1.1, behaviour-neutral)

## Context
`apps/web/src` is layered by kind: `api/` (21 files + tests), `hooks/` (~70), `components/` (129 folders), plus ~20 loose files at the root. Checkpoint C regroups it by feature (TRD §4, ADR 0098). Import paths change; nothing else does: no rendered output, request or assertion changes. Branch `release/1.1.1`; one commit per task, staged by name, pushed after each. Task 3.1 opens by writing ADR 0098 (layout; says it follows TRD §4) and adding it to `docs/README.md` and the ADR column of 3.1–3.9.

## Method for every move task (3.1–3.7)
- **"Test first" here is the existing suite.** Run `pnpm test`, `test:browser`, `lint`, `typecheck` green *before* the task as the baseline; moves use `git mv` (history kept); then fix imports only. Red = broken imports/typecheck after the move; green = same tests, same count, passing. Record the test count before and after in each log line; any difference is a bug.
- **Import rewriting:** a throwaway script in the scratchpad (not committed) rewrites import specifiers for moved files, using relative imports within a feature and `#src/*` when a relative path would climb two levels (existing alias in `tsconfig.app.json`, `tsconfig.browser.json`, Vite; unchanged). `vi.mock('…/api/x.api')` paths in tests are specifiers too; they are rewritten the same way and checked by grep for stale `../api/`, `../hooks/`, `../components/` afterwards.
- **Inside a feature:** `components/<Name>/` (folder, `<Name>.tsx`, `.test.tsx`, `index.ts` unchanged), `hooks/`, `api/`, `fixtures/` (TRD 4.4). No feature-level barrel. Cross-feature imports go straight to the owning feature's path.
- **Shared fixtures:** the `*.fixture.ts` files in `test-support/` move into the feature that owns the data (`job.fixture`→jobs, `feed`→feeds, `gmail`→gmail, `melete`/`gaps`→melete, `syllabus`→melete, `themis`/`themisGoal`→themis, `status`→status, `linkSuggestion`→jobs, `summarizer`→jobs). `me.fixture.ts`, `hookStates.ts`, `noteFixtures.ts` are used across features: they stay in `test-support/` (TRD 4.5 says render helpers and setup only, so `me.fixture`/`hookStates` are the exception: see Open points).
- **Commit message** per task: `refactor: move <area> into src/<dest>`; ADR commit `docs:`. `tasks.md` ticked with a log line listing moved files by group (not file by file), test counts, and "no test file deleted" (3.8 lists deletions).
- **Gate per task:** `pnpm --filter @atlas/web test`, `test:browser`, `lint`, `typecheck`; `build` at 3.9. Root `pnpm test` (doc guards read `apps/web/CLAUDE.md`/architecture paths) at 3.9.
